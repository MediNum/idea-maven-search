# Maven Search — IntelliJ IDEA 插件

IDEA Maven Search 同用法（Tools → Maven Search）的 Maven 组件搜索工具，支持
**多数据源仓库 + 延迟自动择优**：mvn.coderead.cn（国内镜像）+ Maven Central + 用户自定义仓库。

## 功能

- **Tools → Maven Search** 打开右侧工具窗口（若工具窗未注册则回退为对话框）
- **首次打开居中显示使用方式**（13 号字、灰度，标题旁显示插件版本号 v1.4.5）：
  输入关键词搜索 Maven 组件（自动选择延迟最低的仓库）等提示，搜索后自动切换为结果列表
- **界面布局**：返回按钮（←）在搜索框左侧、设置按钮（⚙）在最右侧，均为纯符号；
  **输入框有内容时单击 ← 自动清空输入并回到首页使用方式提示页**；⚙ 进入面板内
  **设置二级页面**（非弹窗）：仓库地址以**表格**展示（每行一个地址，
  **点击单元格直接修改、点击其它区域自动保存**），每行带**延迟测试按钮**（按钮内
  显示延迟时间，点击重新测试），**保存后自动进行延迟测试**；支持添加/删除/恢复默认
- **默认仓库**：mvn.coderead.cn、Maven Central（search.maven.org）、repo1.maven.org、
  repo.maven.apache.org、central.sonatype.com、阿里云 public、华为云、腾讯云（共 8 个，
  可在设置中修改）
- **默认数据源 http://mvn.coderead.cn**：打开工具立即生效（搜索可用），同时自动测速，
  测速完成后按延迟择优
- **输入即搜索**：搜索框宽度 36、**打开默认空**（历史记录在下拉框中）、无"搜索"
  按钮，停止输入 350ms 自动弹出结果列表；Class 模式按类名搜索；**点击搜索框弹出
  下拉列表显示历史查询**（回车/选择历史项/点击结果都会记录，最新在前、去重、上限
  20 条、持久化保存），**下拉框最底部有"清除历史"项**（灰色居中，点击即清空）
- **版本号自动更新**：点击组件自动加载全部版本并选中最新；**双击版本自动复制 Maven
  XML 片段**并弹窗提示"复制成功"，下方同步显示 Maven XML / Gradle 片段
- **二级页面布局**：Maven 介绍（描述）位于版本复制框下方、Maven XML 显示框上方（自动换行）
- 一键复制 **Maven XML** / **Gradle** 片段；**下载 jar**（自定义镜像 → 官方 → 阿里云 依次回退）

## 安装（从磁盘安装）

> ⚠️ 注意：IDEA 2026.2 的 "Install Plugin from Disk" **只认 `.jar` 后缀**（`.zip` 会被
> 判定为非插件包并报 "Fail to load plugin descriptor"）。产物就是 `MavenSearch-1.5.6.jar`（zip/jar 同格式）。

1. IDEA：`File → Settings → Plugins`（或 `Ctrl+Alt+S`）
2. 点击右上角齿轮 ⚙ → `Install Plugin from Disk...`
3. 选择本文件同目录下的 **`MavenSearch-1.5.6.jar`**
4. 重启 IDEA
5. 打开任意项目 → `Tools` 菜单 → `Maven Search`

## 重新构建（本机无需任何网络/Gradle）

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

构建脚本直接用本机安装的 IDEA（`D:\ProgramInstall\IntelliJ IDEA 2026.1.3`，实际平台
build 262.8665 / 2026.2）自带的平台 jar（lib\*）与其 JBR（Java 25）编译，再用 JDK 的
jar.exe 打包，全程零下载。产出 `MavenSearch-1.5.6.jar`。

> 提示：如果换了 IDEA 安装路径，请先修改 `build.ps1` 顶部的 `$IDEA` / `$JBR`。

## 技术说明

- 纯 Java，无第三方依赖：HTTP 用 `java.net.HttpURLConnection`；JSON 用内置微型解析器
  `MiniJson`；mvn.coderead.cn 版本页 HTML 用正则解析。
- 仓库模型（`Repo`）：内置 mvn.coderead.cn（kind=coderead，搜索+版本 API）、
  Maven Central（kind=central，search.maven.org 搜索）；用户自定义地址（kind=generic，
  含 coderead/search.maven.org 的自动识别）。延迟用 `measureLatency`（HTTP 短超时）测量。
- 数据源接口：
  - mvn.coderead.cn：`/search`（JSON）+ `/version`（HTML，含引用次数/日期/描述）
  - Maven Central：`search.maven.org/solrsearch/select`（搜索）+ 仓库
    `maven-metadata.xml`（版本列表，repo1 优先、阿里云镜像回退）
  - 通用仓库（自定义）：`<base>/<g>/<a>/maven-metadata.xml` 版本列表 + 直接下载
- 延迟择优：打开工具后台并行测延迟 → 工具下方状态栏轮询显示（每个 1 秒，Swing Timer）
  → 结束显示延迟最小仓库并自动设为数据源；自定义仓库用 `PropertiesComponent` 持久化。
- 下载候选：延迟最小仓库（若为自定义镜像）→ `repo1.maven.org` → `maven.aliyun.com`。
- 兼容性：`since-build="261.0"`，仅依赖 `com.intellij.modules.platform`。
